# **Hoary Theme Switcher**

Hoary Theme Switcher is a Joomla\! module that easily lets you switch between light and dark mode on your front end (Site) template.

## **Why Use Hoary Theme Switcher**

Switching between light and dark modes using the default back end Joomla\! template is easily done. 

But I couldn't find a simple, lightweight Joomla\! module that does the same thing on the Joomla\! frontend template.

The Hoary Theme Switcher lets your site visitors easily toggle between light and dark mode, just as an administrator would on the back end. 

The module works cleanly by overriding the template front end CSS with a provided scoped CSS containing dark mode colours.

## **How To Use Hoary Theme Switcher**

1. Install the module via the Joomla\! Extensions Manager. You can install via URL by using this URL: [https://github.com/brettvac/hoaryswitcher/releases/latest/download/mod\_hoary.zip](https://www.google.com/search?q=https://github.com/brettvac/hoaryswitcher/releases/latest/download/mod_hoary.zip)  
2. Navigate to Content \> Site Modules (or just click the modules button from the dashboard) and choose the Hoary Theme Switcher module.  
3. Configure the module settings, such as choosing your preferred display style (text, emojis, or Font Awesome icons).  
4. Publish the module in a visible position on your template, such as the Menu position.

Once the module is visible on your site, visitors can now immediately toggle their preferred theme directly by clicking on the displayed module.

## **Hoary Theme Switcher Features**

* **Flicker Prevention**. Verifies if dark mode is set to prevent flickering or FOUC (Flash of Unstyled Content) when the page loads.
* **Remembers Preferences**. Automatically sets a cookie to remember the user's choice across page loads and future visits.
* **Customizable Display**. Choose how the theme switcher is displayed using the available icon style options. The switcher can display an icon along with, optionally, a translatable text label.

## **FAQ**

**Q: Does the Hoary Theme Switcher require jQuery or other heavy libraries?**

**A:** No. The Hoary Theme Switcher is built natively with vanilla JavaScript and CSS, so no jQuery or other heavy libraries are required.

**Q: What Joomla! and PHP versions are required?**

**A:** The Hoary Theme Switcher works with Joomla! versions greater than 4.4 and requires PHP 7.2.5 or later.
